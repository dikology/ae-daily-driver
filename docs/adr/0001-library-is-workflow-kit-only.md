# Library is workflow kit only

`ae-daily-driver` is a showcase library of skills, rules, MCP wiring, and diagrams. It does not store entity content or AE session artifacts. Durable descriptions live in sibling homes; unwrap and closeout run in consuming repos after per-repo install. We rejected keeping touch-maps or a local entity index here — that would fork the semantic layer and blur the stealable-kit story.
